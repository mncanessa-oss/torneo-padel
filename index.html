Reglas configuradas

Parámetros del torneo
01 · Cuatro jugadores

Martín, Marcio, Iván y Lucas. Las estadísticas son individuales, aunque cada partido se juega en dobles.

02 · Seis partidos

Tres combinaciones de parejas, cada una repetida una vez con los jugadores intercambiando drive y revés.

03 · Mejor de tres sets

El partido termina cuando una pareja gana dos sets. No se deben cargar sets posteriores al ganador.

04 · Sets a seis games

Se requiere una diferencia de dos games. A 6–6 se juega tie-break; el resultado del set se registra como 7–6.

05 · Estadísticas

Partidos jugados, ganados y perdidos; sets a favor y en contra, diferencia de sets; games a favor y en contra, diferencia de games.

06 · Guardado local

Los resultados se guardan automáticamente en este navegador. Para compartirlos entre celulares hará falta conectar una base de datos o publicar una versión con sincronización.

Borrar resultados elimina los marcadores guardados en este navegador. Esta acción pide confirmación.
